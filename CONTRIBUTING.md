# Contributing

Thank you for looking at Castellan. The working rules live in [`docs/governance/`](docs/governance/). Read these before opening a pull request:

- [`docs/governance/branching-and-prs.md`](docs/governance/branching-and-prs.md)
- [`docs/governance/commit-conventions.md`](docs/governance/commit-conventions.md)
- [`docs/governance/action-safety-review.md`](docs/governance/action-safety-review.md)
- [`docs/dev/testing.md`](docs/dev/testing.md)
- [`AGENTS.md`](AGENTS.md) if you are a coding agent

English is the language of code, commits, and pull requests. Issues written in Portuguese are welcome.

By contributing, you agree that your work is under the MIT license and that you follow the [Code of Conduct](CODE_OF_CONDUCT.md).
