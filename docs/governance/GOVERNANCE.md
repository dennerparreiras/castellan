# Governance

Denner Parreiras is the maintainer and has the final say. This is a benevolent-dictator project, not a committee.

Someone else becomes a maintainer only when Denner says so in a commit that updates [MAINTAINERS.md](MAINTAINERS.md), and only after they have reviewed safety-kernel changes carefully over time. There is no election and no foundation.

Issues and pull requests are welcome. English is the language of code and of pull requests. Issues in Portuguese are accepted and answered.

The [Code of Conduct](../../CODE_OF_CONDUCT.md) is enforced by the maintainer.
